    Team explanation — eight-module architecture

    This file is the complete pure-JavaScript implementation of OFFICIAL_RULES.md (engine + browser UI, no external dependencies). Board squares use zero-based { col, row } with dark a1 at (0,0). Moves use { start, path, captures, isCapture }. Factories build those plain objects; ES6 classes own behavior.

    1. Constants — players, piece kinds, diagonals, draw limits
    2. BoardUtils — playable geometry, notation, square/piece/move factories
    3. GameState — 8×8 dark-square piece map, turn, counters, fingerprints
    4. MoveGenerator — quiet moves and maximal capture paths
    5. MoveValidator — legal-move and multi-jump selection checks
    6. GameEngine — apply turns, promotion, win/draw, undo stack
    7. UIRenderer — board paint, highlights, status, history
    8. UIEventHandlers — clicks, mandatory captures, multi-jump lock
